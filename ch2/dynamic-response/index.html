读图：激振台台面就是被测系统的“质量块”，信号源给出阶跃或正弦激励，位移探头把台面位移变成电压，示波器看时域、X-Y 记录仪画幅频。一阶系统由 τ 唯一决定： 时间常数处响应到 63.2%，tr = 2.2τ，ts = 3τ，−3 dB 带宽 ωb = 1/τ；二阶系统由 ωn、ζ 决定：超调量 Mp = e−πζ/√(1−ζ²)、峰值时间 tp = π/ωd、谐振频率 ωr = ωn√(1−2ζ²)（ζ < 0.707）、 −3 dB 带宽 ωb = ωn√[(1−2ζ²)+√((1−2ζ²)²+1)]。图中曲线、示波器波形、记录纸墨迹与右侧读数全部由同一套模型实时算出；动画按调节时间自动压缩时间轴，读数始终是真实时间。
